# 🎮 Hangman Game Using Python

## 📌 About the Project
Hangman is a beginner-friendly word guessing game developed using Python. The computer randomly selects a word, and the player must guess the hidden word by entering one letter at a time within a limited number of attempts.

## 🚀 Features
- Random word selection.
- Guess one letter at a time.
- Maximum 6 incorrect attempts.
- Displays correctly guessed letters.
- Prevents repeated letter guesses.
- Shows win or game-over messages.

## 🛠️ Technologies Used
- Python
- Random Module

## 📚 Python Concepts Used
- Lists
- Sets
- Strings
- For Loop and While Loop
- If-Else Statements
- Conditional Statements
- Break and Continue

## 🎯 How to Play
1. Run the Python program.
2. The computer selects a random word.
3. Enter one alphabet at a time.
4. Guess the hidden word within 6 incorrect attempts.
5. Win by guessing all the letters correctly!
